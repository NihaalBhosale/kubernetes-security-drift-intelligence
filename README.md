# Kubernetes Security Drift Intelligence

### Using Attack Path Analysis and Rule-Based Risk Assessment

Software engineering project (Phase 2 – Design and Implementation).

The system captures Kubernetes resources, compares them with a trusted baseline, detects configuration drift, and evaluates changes using YAML-based security rules to produce an impact score.

## Pipeline

**Kubernetes Cluster → Resource Collection → Snapshot (Normalize + SHA-256) → Baseline → Drift Detection → Rule-Based Evaluation → Impact Score**

## Run It

### Colab Demo

Open the notebook in Google Colab and select:

**Runtime → Run all**

The notebook runs the implementation using the saved sample snapshots and demonstrates the drift detection and rule-based evaluation pipeline.

### Local Kubernetes Cluster

To run the implementation against a local Kubernetes cluster:

1. Install Python 3.10 or later.
2. Install the dependencies:

```bash
pip install -r requirements.txt
```

3. Make sure `kubectl` is configured and connected to your Kubernetes cluster, such as a `kind` or Docker Desktop cluster.
4. Run the Python implementation generated by the notebook from the project root:

```bash
python -m app.main
```

> **Note:** The Python `app/` modules are generated by the Colab notebook using its implementation cells.
